## 🔍 ИССЛЕДОВАНИЕ: Доступ к контактам и их передача

### Основные выводы

**✅ ДА, приложение ИМЕЕТ доступ к контактам**  
**⚠️ ЧАСТИЧНО - контакты отправляются только при явном действии пользователя**

### Приоритет риска

- **Приоритет:** P2
- **Текущий риск:** высокий privacy risk, но ниже, чем overlay/install-packages, так как для отправки контакта требуется действие пользователя.
- **Как изменился риск:** по сравнению с ранними опасениями массовой выгрузки риск **не выглядит усиленным**; в текущем статическом анализе подтвержден доступ к адресной книге, но не подтверждена скрытая автоматическая отправка всей телефонной книги.

## Сценарии использования контактов

### ✅ **Легитимные случаи:**

1. **Отправка контакта в сообщении**
   - Пользователь выбирает контакт для отправки
   - Контакт отправляется в формате vCard
   - Требует явного действия пользователя

2. **Поиск друзей по телефонной книге**
   - Сопоставление номеров с пользователями приложения
   - Предложение добавить знакомых

3. **Интеграция с системными контактами**
   - Добавление контактов из мессенджера в телефон
   - Синхронизация данных контактов

### ⚠️ **Потенциально подозрительные случаи:**

1. **Массовая загрузка контактов**
   - Отправка всей телефонной книги на сервер
   - Создание социального графа пользователей

2. **Скрытый доступ к контактам**
   - Чтение контактов без уведомления пользователя
   - Использование данных для аналитики

## Что НЕ найдено в коде

### ❌ **Массовая отправка контактов:**
- Не найден код автоматической загрузки всех контактов
- Нет скрытой передачи телефонной книги на сервер
- Отправка происходит только при явном действии пользователя

### ❌ **Скрытый сбор данных контактов:**
- Не обнаружена интеграция с MyTracker для отправки контактов
- Нет автоматической синхронизации с внешними серверами

## Оценка рисков

### 🟡 **СРЕДНИЙ РИСК** - Стандартное использование

#### Положительные аспекты:
- Доступ к контактам используется для легитимных функций
- Отправка контактов требует подтверждения пользователя
- Нет явных признаков массового сбора данных

#### Риски:
- **Широкие разрешения** - полный доступ ко всем контактам
- **Потенциал злоупотребления** - техническая возможность читать все контакты
- **Неопределенность** - возможны скрытые функции в обфусцированном коде

## Рекомендации по безопасности

### 🔐 **Для пользователей:**

1. **Проверьте разрешения**
   - Отзовите доступ к контактам, если не используете функции отправки контактов
   - Регулярно проверяйте разрешения приложений

2. **Осторожность при отправке**
   - Не отправляйте контакты неизвестным ботам
   - Проверяйте, кому отправляете личную информацию

3. **Альтернативы**
   - Используйте мессенджеры с минимальными разрешениями
   - Signal не требует доступа к контактам для основных функций

### 🛡️ **Общие меры предосторожности:**

- Регулярно аудируйте разрешения приложений
- Используйте отдельный телефон для конфиденциальных контактов
- Рассмотрите использование более приватных альтернатив

## Заключение

**Приложение ru.oneme.app имеет полный доступ к контактам, но использует его преимущественно для стандартных функций мессенджера.**

### Ключевые выводы:

✅ **Не обнаружено массовой отправки контактов на сервер**  
✅ **Отправка контактов требует действий пользователя**  
⚠️ **Широкие разрешения создают потенциал для злоупотреблений**  
⚠️ **Обфусцированный код может скрывать дополнительную функциональность**

**Рекомендация:** Использование контактов в приложении выглядит стандартно, но учитывая другие найденные проблемы (сбор данных об установленных приложениях, REQUEST_INSTALL_PACKAGES), рекомендуется ограничить или отозвать доступ к контактам.
